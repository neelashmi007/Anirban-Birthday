# Photo Assets Directory

Drop your real photographs of Anirban and your friendship here!

### Expected filenames:
* `friendship-01.jpg` — Memory 01 (e.g. Early days / classic moment)
* `friendship-02.jpg` — Memory 02 (e.g. Height moment / fun hangout)
* `friendship-03.jpg` — Memory 03 (e.g. Unfiltered chaos / laughs)
* `friendship-04.jpg` — Memory 04 (e.g. The anchor / showing up)
* `friendship-05.jpg` — Memory 05 (e.g. Mimicry session / golden memory)
* `friendship-06.jpg` — Memory 06 (e.g. Brotherhood / Dec 2025 – Jan 2026)

### How to customize:
You can edit the captions, dates, or add more photos by simply opening `content/gallery.ts`.
If no image files are placed here, the website automatically displays graceful Polaroid art cards with camera illustrations and zero broken icons.
